# Ubuntu 16X16 矩阵光开关控制脚本使用说明

## 概述

这是一个专为 **OXC-16X16-1U-LP 16X16 矩阵光开关** 设计的控制脚本，严格按照《矩阵式16X16光开关 使用说明》中的 **OSW 协议** 实现。脚本使用Bash编写，通过TCP连接控制光开关设备。

协议要点（见说明书 4.4 上位机监控说明）：

- 设备每次只能执行一个指令，必须等待返回响应后才能发送下一条指令
- 指令使用大写字母
- 尖括弧 `<` 作为开始符、`>` 作为结束符
- 不能同时有两路输入选择同一输出，否则是非法命令（设备返回 `<ER>`）

## 系统要求

- Ubuntu 18.04+ (或其他Linux发行版)
- Bash 4.1+
- netcat (nc命令)

## 安装依赖

```bash
sudo apt-get update
sudo apt-get install netcat-openbsd
```

## 使用方法

### 1. 设置脚本权限

```bash
chmod +x chinese_ubuntu_optical_control.sh
```

### 2. 运行脚本

```bash
./chinese_ubuntu_optical_control.sh
```

### 3. 配置设备IP与端口

打开脚本文件，修改顶部的 **设备配置区**：

```bash
# ================== 设备配置区 (修改这里) ==================
SWITCH_IP="192.168.136.200"   # 光开关IP地址
SWITCH_PORT=4001              # 光开关TCP端口
# ==============================================================
```

保存后直接运行脚本即可自动连接，**无需每次输入IP地址**。设备IP/端口变化时只需修改这一处。

### 4. 主要功能

| 菜单 | 功能 | 对应指令 |
|---|---|---|
| 1 | 查询设备信息 | `<INFO_?>` |
| 2 | 查询当前光路状态 | `<OSW_A_?>` |
| 3 | 建立光路连接 | `<OSW_SW_...>` (整路切换) |
| 4 | 断开光路连接 | `<OSW_SW_...>` (整路切换) |
| 5 | 批量建立连接 | `<OSW_SW_...>` (整路切换) |
| 6 | 批量断开连接 | `<OSW_SW_...>` (整路切换) |
| 7 | 断开所有连接 | `<OSW_SW_...>` (整路切换) |
| 8 | 网络设置 (IP/网关/子网掩码/TCP端口) | `<IP_?>`、`<SET_IP_...>` 等 |
| 9 | 面板按键权限 (查询/设置) | `<KEY_?>`、`<SET_KEY_x>` |
| 10 | 测试连接功能 | 自动断开/重连 In1 |
| 11 | 自定义指令 | 任意OSW指令 |
| 12 | 重启设备 | `<RESET>` |
| 13 | 恢复出厂设置 (仅网络参数) | `<RESTORE>` |
| 14 | 重新连接设备 | - |
| 0 | 退出 | - |

## 操作格式说明

### 单个连接/断开操作格式

`输入端口号,输出端口号`，端口范围 **1-16**

示例：`1,3` (连接输入端口1到输出端口3)

### 批量操作格式

`input1,output1;input2,output2;...`

示例：`1,3;2,4;3,5`

注意：同一批中输入端口不可重复。

## 光路切换实现说明

OSW协议没有按端口对的增删命令，通道切换通过 **一次 `<OSW_SW_...>` 指令设置全部16路** 完成：

```
<OSW_SW_a_b_c_..._p>
```

每个取值 `a~p` 规则（见说明书）：

- 取值 `01~16`：该输入端口连接到对应输出端口
- 取值 `00`：该路为0通道，不通光
- **取值不能相同**（两个输入不能选择同一输出，否则为非法命令）

因此脚本"建立/断开连接"的执行流程为：

1. 发送 `<OSW_A_?>` 查询当前16路状态
2. 修改对应输入端口的取值（建立=目标输出号，断开=`00`）
3. 非法命令预检查（输出端口冲突时本地拒绝，不发送）
4. 发送整路切换指令 `<OSW_SW_...>`，等待 `_OK` 响应
5. 再次 `<OSW_A_?>` 验证切换结果

## OSW指令参考（依据说明书）

### 光开关指令

| 指令 | 说明 | 成功返回 |
|---|---|---|
| `<OSW_A_?>` | 查询通道状态 | `<OSW_01_02_..._16>` |
| `<OSW_SW_v1_..._v16>` | 通道切换(整路16个值) | `<OSW_SW_..._OK>` |

### 设备参数指令

| 指令 | 说明 | 成功返回 |
|---|---|---|
| `<INFO_?>` | 查询设备信息 | `<OSW16X16-SM_VER1.00_SN01234567890_C06.02.00020>` |
| `<IP_?>` | 查询IP地址 | `<IP_192_168_002_011>` |
| `<SET_IP_xxx_xxx_xxx_xxx>` | 设置IP (000~255，重启生效) | `<SET_IP_OK>` |
| `<GW_?>` | 查询网关 | `<GW_192_168_002_001>` |
| `<SET_GW_xxx_xxx_xxx_xxx>` | 设置网关 (重启生效) | `<SET_GW_OK>` |
| `<SM_?>` | 查询子网掩码 | `<SM_255_255_255_000>` |
| `<SET_SM_xxx_xxx_xxx_xxx>` | 设置子网掩码 (重启生效) | `<SET_SM_OK>` |
| `<TCPP_?>` | 查询TCP端口 | `<TCPP_04001>` |
| `<SET_TCPP_xxxxx>` | 设置TCP端口 (00000~65534，重启生效) | `<SET_TCPP_OK>` |
| `<KEY_?>` | 查询面板按键权限 | `<KEY_0>` 或 `<KEY_1>` |
| `<SET_KEY_0>` / `<SET_KEY_1>` | 禁止/允许面板按键 | `<SET_KEY_x_OK>` |
| `<RESET>` | 重启设备 | 网口无返回，成功后TCP连接自动断开 |
| `<RESTORE>` | 恢复出厂设置 (仅恢复网络参数) | 网口无返回，成功后TCP连接自动断开 |

失败统一返回 `<ER>`。

## 出厂缺省配置（依据说明书）

| 项目 | 默认值 |
|---|---|
| 光路通道 | In1→Out1 ... In16→Out16 |
| 设备IP | 192.168.1.178 (TCP Server) |
| 设备网关 | 192.168.1.1 |
| 子网掩码 | 255.255.255.0 |
| TCP端口号 | 4001 |
| 串口 | 9600, 8位数据位, 1位停止位, 无奇偶校验 |
| 面板按键 | 允许使用 |
| LCD背光 | 1分钟 |

## 特性

- **协议合规** - 完全符合说明书OSW协议（大写、`<>`定界、单指令串行执行）
- **等待完整响应** - 每条指令发送后阻塞等待完整 `<...>` 响应，满足"每次只能执行一个指令"要求
- **切换后验证** - 每次光路切换后自动重新查询状态并逐项验证
- **非法命令预检查** - 两个输入选择同一输出时本地直接拒绝
- **固定设备配置** - IP/端口在脚本顶部配置区修改, 启动自动连接, 无需每次输入
- **输入验证** - 严格验证光端口(1-16)及批量操作格式
- **颜色输出** - 不同类型消息用颜色区分
- **优雅退出** - 支持q键快速返回菜单，退出时自动清理连接
- **网络参数设置** - 支持设置IP/网关/子网掩码/TCP端口，并提示重启生效
- **按键锁定** - 支持通过串口/网口指令锁定面板按键，防止误操作

## 安全注意事项

- 确保网络连接安全，仅在授权的网络环境中使用
- 避免在生产环境中进行未经测试的批量操作
- 远程控场时建议先 `<SET_KEY_0>` 锁定面板按键，防止现场误操作
- `<RESET>` 和 `<RESTORE>` 会导致TCP连接自动断开，操作前请确认
- 修改IP/TCP端口后需重启设备才生效，重启前无法用旧参数连接

## 故障排除

### 连接失败

1. 检查IP地址是否正确（出厂默认 192.168.1.178）
2. 确认设备电源和网络连接
3. 验证防火墙设置，检查端口 4001 是否开放
4. 确认设备TCP端口是否被修改过（可用 `<TCPP_?>` 查询）
5. 修改过网络参数的设备，参数重启后才生效

### 命令返回 `<ER>`

1. 检查是否两个输入选择了同一输出（非法命令）
2. 检查端口取值是否在 00~16 范围内
3. 检查指令格式是否正确（大写、`<>`定界）

### 命令超时

1. 确认设备在线且未处于忙碌/重启状态
2. 尝试重新连接设备（菜单14）
3. 检查网络延迟和稳定性

## 版本更新历史

### v2.0 (最新版本)

- 严格按照《矩阵式16X16光开关 使用说明》重写通信协议（OSW协议）
- 默认IP 192.168.1.178、默认TCP端口 4001（出厂缺省配置）
- 光端口范围改为 1-16
- 光路切换改为"查询状态 → 修改16路状态表 → 整路 `<OSW_SW_...>` 切换 → 验证"模式
- 新增：设备信息查询(`<INFO_?>`)、网络设置(IP/网关/子网掩码/TCP端口)、面板按键权限(`<SET_KEY_x>`)、重启(`<RESET>`)、恢复出厂(`<RESTORE>`)
- 新增非法命令预检查（两个输入不能选择同一输出）
- 每次切换后自动验证

### v1.3 及更早版本（已废弃）

- 基于 Polatis SCPI 协议（`:oxc:swit:conn:add` 等，端口 5025，端口范围1-32）
- 与 OXC-16X16-1U-LP 设备的 OSW 协议不匹配，不再适用

## 与原版差异

相比原始的 Polatis SCPI 版本，本版本：

- 协议从 SCPI 改为本设备的 **OSW 协议**（`<>` 定界、大写）
- "单端口对增删"改为"查询状态 → 修改16路状态表 → 整路切换 → 验证"
- 光端口范围从 1-32 改为 **1-16**
- 默认TCP端口从 5025 改为 **4001**
- 默认IP 192.168.1.178
- 新增网络参数设置、按键锁定、设备重启/恢复出厂等功能
- 移除了原SCPI特有的"端口规模查询"和"错误日志查询"（本设备无对应指令）
